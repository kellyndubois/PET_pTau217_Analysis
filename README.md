<b>Project Title: Amyloid Burden Only Partially Mediates Racial Differences in Plasma pTau-217</b>

<b>Overview</b>

This repository contains code used to analyze racial differences in plasma pTau-217 in relation to amyloid burden (measured in Centiloids) and clinical diagnosis across multiple cohorts.

The primary goal of this project is to determine whether differences in plasma pTau-217 levels between non-Hispanic White (NHW) and Black/African American (B/AA) participants are explained by amyloid burden or reflect differences in other
biological processes.

<b>Data Sources</b>

This analysis integrates data from multiple cohorts, including:
MADRC (Michigan Alzheimer's Disease Research Center) cohort
NACC (National Alzheimer’s Coordinating Center)

Data include:
Plasma biomarkers (pTau-217)
Amyloid PET (Centiloids)
Clinical diagnosis (CU, MCI, DAT)
Demographics and covariates (age, sex, APOE, education)

⚠️ Note: Raw data are not included in this repository due to data use agreements.
